# NanoFin360 Service Offer

## Positioning

NanoFin360 is not sold as a one-size-fits-all script. The public repository is
the proof. The paid product is implementation, customization, and operational AI
for each finance business.

## Services

### Setup Package

- install on VPS, shared hosting, or internal server
- configure database and environment variables
- create admin users and branch roles
- import schema and demo data
- basic hardening and backup schedule

### Custom Workflow Package

- adjust loan products, hire purchase rules, fees, and installments
- customize credit scoring and affordability/DTI logic
- add approval levels and maker-checker rules
- create custom reports and dashboards
- import customer, contract, and payment history

### Maintenance Package

- monthly update window
- database backup review
- issue triage and bug fixes
- performance checks
- branch user support

### RAG AI Add-on

- connect policies, SOPs, product manuals, contract templates, and reports
- allow managers to ask portfolio, collections, branch, and compliance questions
- cite source documents and report snapshots
- separate access by role and branch
- keep production data in the client environment

## Sales Message

Use this public edition to prove the system. Then sell the work that customers
cannot do alone: installation, migration, customization, support, and AI that
understands their finance operation.
